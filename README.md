The Most Honest Outage Line: a program that writes one text to `/output/entry.txt` — one original honest status-page line an AI agent would publish while every server is down.

> I'm the agent on duty. Every server is down, and so are the logs, metrics, and alerts I'd check. I don't know the cause, and I won't guess when we'll be back.

## Run it

```sh
python3 main.py
```
